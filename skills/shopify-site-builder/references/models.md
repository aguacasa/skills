# Match tools to the task

Use the user's available models and tools. Do not require a named provider or
assume a subscription, price, model ranking, or permanent capability level.

For unfamiliar architecture, 3D scenes, or difficult scroll bugs, use enough
reasoning and iteration to inspect the whole interaction. For isolated copy or
layout fixes, keep the workflow proportionate. Use measured checks, screenshots,
and source evidence rather than assuming a more expensive model guarantees quality.
