# Optional preset: Clean explainer

A starting style for talking-head explainers. Apply only when selected. Ask which
parts to keep; current instructions override every example value below.

## Edit and visual style

- Script-led cuts that preserve meaning, a strong opening, and a complete ending.
- Confident delivery, minimal hesitation, and natural speech. Retain fluent side
  glances; remove reading resets. Do not accelerate speech to hit a target runtime.
- For static footage, begin with clearly distinct framing changes roughly every
  1.5–2 seconds and judge rhythm. Reduce their frequency when the footage moves.
  These are starting points, not a timer for speech cuts.
- Use a few brief key-term highlights rather than constant decoration. Bold white
  text with a black outline on a rounded black box. Place below the face, clear of
  gestures and social UI, with space reserved for captions if needed.
- For explanatory diagrams: navy `#0A1830`, light blue `#7CC7FF`, white text, with
  secondary fills `#162F4E` and `#1E4169`. Keep recurring diagrams visible and
  highlight the currently discussed part. Avoid whole-screen flashing.
- Captions remain a per-video choice. A caption-free review is an option, not a
  universal ban. When requested, offer short uppercase phrases with a readable
  outline and an active-word highlight; confirm its color.
- Clean, natural dialogue. Use restrained rumble/noise reduction, modest presence,
  and gentle dynamics. Avoid metallic denoising, abrupt gates, or clipped breaths.
  Music and profanity treatment remain explicit choices.

## Review and posting

Show the cut before preparing posting copy unless the brief requests both at once.
After final approval, use one plain-text title and one concise description shared
across the selected platforms. Include natural topic terms, the real CTA, and only
relevant optional hashtags. Never promise algorithmic performance.

## Organization

Offer a separate dated folder per video, with originals/reference assets and the
complete edit together. Let the user choose the root location, timezone, and date
format. Keep revisions in the original project.

This preset contains no biography, local source references, or external-service
permissions. It can be paired with the direct-explainer script preset.
