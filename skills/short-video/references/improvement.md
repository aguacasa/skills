# Remembering editing preferences

Use this only when the user asks to remember feedback or improve their profile.
A requested change to one video applies immediately to that edit, not to all
future work.

1. Read the profile, current feedback, and project notes. Prefer explicit user
   corrections and the approved result over earlier assistant suggestions.
2. Separate lasting preferences, one-video choices, production corrections, and
   unresolved experiments. Ask only when the intended scope is unclear.
3. Update the user's private profile with lasting preferences and replace
   contradictions. Keep project-only decisions in `edit/project.md`. Never turn
   one approved video, upload, or runtime into universal permission or a mandate.
4. Report the few preferences changed. Do not rewrite the public skill, bundled
   presets, other tools, or global memories unless separately requested.
